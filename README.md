# GRA-Sklad WMS

Складская система для производства БАД: сотрудники и доступы, товары и штрихкоды, сырьё и технологические карты, складские операции и интеграции с маркетплейсами.

Backend — Express и PostgreSQL; frontend — React, Vite, Tailwind CSS. Схема рабочих таблиц использует суффикс `_s`.

## Запуск

1. Скопировать `backend/.env.example` в `backend/.env`. Заполнить `DB_*`, `JWT_SECRET`, `SEED_ADMIN_LOGIN` и собственный `SEED_ADMIN_PASSWORD`. Для дополнительных интеграций заполнить соответствующие токены и параметры внешней БД.
2. Установить зависимости: `npm ci --prefix backend`, `npm ci --prefix frontend`.
3. Запустить backend из каталога `backend`: `npm run dev`. Схема и начальные настройки создаются при запуске; существующий администратор сохраняется, для нового требуется заданный пароль.
4. Запустить frontend: `npm --prefix frontend run dev`. При необходимости задать `VITE_API_PROXY_TARGET` в окружении Vite в соответствии с портом backend.

Настройки по умолчанию используют localhost; реальные пароли и рабочие подключения исключены из исходников. Импорт каталога настраивается через `CATALOG_SOURCE_DIR`.

## Развёртывание

В `.github/workflows/` сохранены шаблоны развёртывания и резервного копирования с ручным запуском. Они требуют настройки собственных GitHub Secrets и сервера. Документация модулей находится в `docs/`.
